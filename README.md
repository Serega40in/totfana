# КЮН — Platform MVP

Первый визуальный MVP платформы КЮН: marketplace + social layer + AI-first publishing.

## Что уже есть
- минималистичная responsive-витрина;
- поиск;
- категории;
- карточки товаров и услуг;
- социальная лента;
- лёгкая авторизация без пароля (UX-концепт);
- добавление предложения через естественный текст;
- AI-упаковка карточки (демо UX);
- визуальный задел под будущую экономику КЮН/QUN;
- полностью автономный `index.html`, без сборки и зависимостей.

## Следующий слой
1. Supabase: users / profiles / listings / likes / follows / messages.
2. Telegram / email / passkey authentication.
3. Реальный AI-парсер объявления → title/category/description/tags/price/media.
4. Медиа-хранилище.
5. Лента + подписки + чаты.
6. Заказы / сделки.
7. QUN wallet и платежный слой — после юридической и технической проработки.
